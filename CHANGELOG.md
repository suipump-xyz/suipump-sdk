# Changelog

## [0.1.0] - 2026-05-15

### Added
- Initial public SDK preview release
- Token creation via 2-click OTW flow (`preparePublish`, `confirmCreate`)
- PTB builder for buy/sell with slippage protection
- Real-time WebSocket streams (tokens, trades, graduations, chat, KOTH, reputation)
- Atomic batch buy PTB (up to 10 tokens)
- Copy-trade subscription with webhook delivery
- Walrus media upload and retrieval
- Portfolio tracking (holdings, trades, overview)
- Transport-agnostic client (gRPC, GraphQL, JSON-RPC)
- Full TypeScript type definitions with branded types
- 186+ test suite with Vitest
