# Security Policy

## Reporting a Vulnerability

Report security vulnerabilities privately via **GitHub Security Advisories**:

https://github.com/suipump-xyz/suipump-sdk/security/advisories/new

Do not disclose the issue publicly until it has been addressed and a patch released.

We will acknowledge receipt within 48 hours and provide a timeline for resolution.

## Scope

- Smart contracts (`suipump::*` modules)
- Backend API endpoints
- PTB builder logic
- SDK client implementations

Out-of-scope: third-party dependencies, frontend UI issues.
